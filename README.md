# 🚀 Tecnoven App - Propuesta de Aplicación Móvil (Front-End)

Este proyecto es un **prototipo Front-End funcional** creado desde cero para proponer la primera aplicación móvil oficial del proveedor de internet **Tecnoven**. 

Actualmente, la empresa gestiona a sus usuarios exclusivamente a través de un portal web. El objetivo de este proyecto es trasladar esas funciones a una experiencia móvil nativa, intuitiva y rápida, desarrollada completamente en React.

⚠️ **Nota:** Este es un proyecto estrictamente Front-End (sin conexión a una base de datos real) diseñado para demostrar maquetado, lógica de componentes en React y diseño de interfaces (UI/UX).

---

### ✨ Funcionalidades del Prototipo
La interfaz integra las herramientas esenciales que todo cliente necesita tener en su teléfono:

- 📊 **Estatus de Cuenta y Plan:** Visualización inmediata del estado del servicio (Activo/Desactivado) y consulta de deudas pendientes.
- 💳 **Gestión de Pagos:** Flujo optimizado para registrar pagos y transferencias de forma rápida y sencilla.
- ⚡ **Test de Velocidad Wi-Fi:** Módulo integrado para comprobar el rendimiento de la conexión directamente desde la app.
